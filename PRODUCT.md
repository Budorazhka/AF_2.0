# Aurum Fort

## Register

brand

## Users and purpose

Prospective buyers select a residence in the existing apartment chessboard, compare plans, areas, prices and availability, and contact sales. The current task adds the already approved 3D model and interior concept to residences 205, 305, 405 and 505 using the shared 40.5 m² plan.

## Existing identity

Preserve the site's light palette, navy text, restrained gold accents, Montserrat and Tenor Sans typography, and existing residence drawer. No new brand direction is part of this change.

## Design principles

- Keep the apartment and its price in context when viewing media.
- Label proposed interiors «Вариант ремонта».
- Show large images and a usable 3D view, with technical generation notes outside customer-facing screens.
- Load optional media only when requested.
- Preserve availability, floor, area and enquiry behavior.

## Accessibility

Use labelled keyboard-operable tabs, visible focus, image descriptions, reduced-motion support, and layouts that fit narrow phone screens. No additional accessibility requirements were supplied.
