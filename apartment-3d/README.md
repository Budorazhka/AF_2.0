# 3D-планировки Aurum Fort

Объёмные реконструкции всех восьми типов квартир, которые есть на сайте. Модели
строятся кодом из размеров поэтажного плана — без внешних библиотек и без интернета.

```
python build.py            # собрать все квартиры
python build.py 66 26-1    # собрать выбранные
node cutaway.test.cjs      # проверить режим «срез стен» и чистоту столешниц
node ../js/residence-media.test.cjs   # проверить привязку к шахматке
```

## Что где лежит

| Файл | Назначение |
| --- | --- |
| `lib.py` | примитивы (`box`, `wall`, `slab`, `band`, `glazing`…), экспорт GLB, сборка вьюера |
| `units/u*.py` | геометрия одной квартиры: контур, стены, проёмы, мебель |
| `build.py` | собирает квартиры, проверяет пересечения, раскладывает файлы |
| `viewer-template.html` | вьюер на чистом WebGL: вращение, вид сверху, срез стен, скрытие мебели и фасада |
| `units-out/<слug>/` | результат сборки: `apartment.glb`, `scene.json`, автономный `index.html` |
| `../assets/residences/<слug>/` | то, что забирает сайт: `model.html` (iframe в шахматке) и `apartment.glb` |

## Как снимались размеры

Источник — `aurum-fort-floor-plans.pdf` (векторный экспорт из ArchiCAD). Масштаб берётся
от несущих колонн: они 40×40 см и в PDF занимают ровно 4,06 пункта, то есть
0,0985 м/пункт. Контуры квартир извлекаются как залитые полигоны — их площади
совпадают с таблицей этажа (70,1 / 51,7 / 38,9 / 35,7 / 26,1 / 21,6 м²), поэтому
границы и осевая сетка заданы точно, а не на глаз. Планировки на сайте
(`assets/img/plans/`) задают расстановку мебели, чертёж — стены и проёмы.

Общее для всех: потолки 2,80 м, двери 2,20 м, внешние стены 20 см, колонны 40×40 см
выступают внутрь помещения на 20 см. Ось Y направлена вверх, единицы — метры,
модели открываются в Blender и Three.js как обычный glTF 2.0.

## Проверки при сборке

`build.py` не выпускает модель, пока мебель пересекает стену или колонну: именно так
в квартире 66 колонна оказалась поверх варочной панели, а холодильник — в углу колонны.
Вторая проверка ловит мебель, уехавшую за пределы квартиры. `cutaway.test.cjs`
дополнительно следит, чтобы в режиме среза стены и высокие шкафы опускались ниже
столешницы, а над проёмами не оставалось перемычек.

## Интерьерные визуализации

Вкладка «Вариант ремонта» в шахматке берёт пять ракурсов из
`assets/residences/<слug>/01-overview.png … 05-bathroom.png`. Сейчас они есть только
у 40,5 («Ар-деко», промпты — в `art-deco-2026/prompts.md`); у остальных типов вкладка
показывает заглушки. Чтобы подключить новый набор: положить пять файлов в папку
квартиры и добавить название стиля в `interior` соответствующей записи
`UNITS` в `js/residence-media.js`.
