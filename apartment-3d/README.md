# Квартира 66,0 м² по поэтажному плану (Aurum Fort)

Откройте `index.html` в браузере. Модель вращается мышью, масштабируется колёсиком / щипком. Кнопки панели позволяют посмотреть сверху, переключить высоту стен (архитектурный срез), скрыть фасадное обрамление или мебель, а также скачать GLB-модель. Интернет и установка зависимостей не нужны.

`apartment.glb` — модель в метрах, ось Y направлена вверх; стены полной высоты (2,80 м). Импортируется в Blender, Three.js и другие 3D-пакеты через стандарт glTF 2.0. Каждый элемент имеет имя и группировку.

## Параметры и основа

Модель построена на основе поэтажных планов комплекса Aurum Fort (`aurum-fort-floor-plans.pdf`, резиденции №204, 304, 404, 504) и чертежа планировки:
*   **Внутренняя площадь (интерьер): 51,7 м²**
    *   Прихожая/коридор со входом на северо-западе.
    *   Совмещенный санузел (ванна, унитаз, умывальник с зеркалом).
    *   Кухня-гостиная с выходом на видовую террасу (кухонный гарнитур, холодильник, варочная панель, мойка, барная стойка, обеденный стол со стульями, угловой диван, столик, ТВ-консоль).
    *   Изолированная спальня с гардеробом, кроватью king-size и выходом на отдельный балкон.
*   **Балкон спальни: 4,8 м²** (ограждение из тонированного синего стекла).
*   **Терраса гостиной: 9,5 м²** с характерным для архитектуры Aurum Fort граненым оригами-обрамлением фасада.
*   **Общая проектная площадь: 66,0 м²**

Конструктивная основа: 9 монолитных железобетонных колонн 40×40 см (по осям 8, 9, 10), внешние стены 20 см, высота потолков 2,80 м.

Повторная генерация: `python build.py`. Геометрия хранится также в `scene.json`. Модель автоматически экспортируется в `assets/residences/66/model.html` для веб-интеграции.
